Backend stack
Custom PHP MVC (not Laravel). Core/ is the framework. Front controller: public/index.php.
Config: copy config/database-sample.php and optional config/app-sample.php.
Local host: http://cms.local (Apache vhost on the machine → public/; do not add a vhost file to this repo).

API
REST under /api/: auth, pages, posts, media, notifications, settings, meta error codes.
Envelope { success, data, error }. Bearer App\ApiToken. Contract: docs/API_CONTRACT.md
Postman: docs/postman/Simple-CMS-API.postman_collection.json (baseUrl e.g. http://cms.local).

Auth and security
Session (Core\Auth), CSRF on admin POSTs, optional email 2FA.
Backup ZIP via UI/CLI; restore is CLI-only.

Frontend
Server-rendered PHP. Bootstrap 5. External JS only (ADR-0006).
Visual builder: public/assets/js/builder/ (no iframe).
