# Play · Build · Sound

CMS style pack for **gaming**, **web development**, and **music**.

- Cyan custom palette (light studio / HUD vibe)
- Card blog grid, pill nav, dramatic headings
- Blog kicker: `BUILD · PLAY · SOUND`

## Zip

Built as `cms-style-pack-play-build-sound.zip` in:

- `docs/samples/`
- `public/assets/theme-packs/`

Rebuild:

```bash
php cli/build_style_pack.php play-build-sound
```

Or: `php cli/build_sample_style_pack.php` (also builds this pack).

Import via Customize → Style pack upload, or download from **Play · Build · Sound** in Customize / General.
