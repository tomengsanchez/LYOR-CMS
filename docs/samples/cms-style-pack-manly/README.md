# Manly

CMS style pack for a **lodge / workshop / men’s magazine** look.

- Dark oak & leather custom palette, copper accent
- Serif type, square corners, editorial chrome, magazine blog
- Blog kicker: `IRON SHARPENS IRON`

## Zip

Built as `cms-style-pack-manly.zip` in:

- `docs/samples/`
- `public/assets/theme-packs/`

Rebuild:

```bash
php cli/build_style_pack.php manly
```

Or: `php cli/build_sample_style_pack.php` (builds all packs).

Install via Customize / General → **Manly (oak, iron, leather)**, or download `?pack=manly`.
